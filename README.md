# AutoClicker

마우스 클릭과 키보드 입력을 녹화해 그대로 반복 재생하는 Windows용 매크로 프로그램입니다.
녹화한 매크로 여러 개를 순서대로 엮어 하나의 합성 매크로로 실행할 수도 있습니다.

## 주요 기능

**녹화와 재생**

- 마우스 왼쪽/오른쪽 클릭과 키보드 누름/뗌을 입력 간 지연시간과 함께 녹화
- 지정 횟수 반복 또는 무한 반복 재생
- 1회 예상 소요시간, 반복 진행률, 남은 시간 표시
- 다중 모니터 및 모니터별 DPI 지원

**매크로 편집**

- 이벤트 추가, 복사, 붙여넣기, 삭제
- 이벤트별 지연시간과 설명 편집
- 매크로 복사, 순서 변경, 다중 선택 삭제

**합성 매크로**

- 기본 매크로와 단발 입력을 원하는 순서로 구성해 실행
- 스텝별 지연시간, 기본 매크로별 반복 횟수 설정

변경한 내용은 자동으로 저장됩니다.

## 요구 사항

- Windows x64
- 관리자 권한 (실행할 때 UAC 확인 창이 나타납니다)
- 소스에서 빌드하려면 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

관리자 권한은 게임처럼 관리자 권한으로 실행된 프로그램의 입력까지 녹화하기 위해 필요합니다.

## 빌드 및 실행

```bash
git clone https://github.com/Arongbang/AutoClicker.git
cd AutoClicker
```

관리자 권한으로 연 터미널에서 바로 실행합니다.

```bash
dotnet run
```

.NET을 설치하지 않은 PC에서도 실행할 수 있는 단일 exe로 배포하려면 다음 명령을 사용합니다.

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

결과물은 `publish\AutoClicker.exe`입니다. `publish` 폴더에 `.dll` 파일이 함께 생성되면 exe와 같은 폴더에 두고 실행하세요.

## 사용법

### 단축키

다른 창을 사용하는 중에도 동작합니다.

| 키 | 동작 |
| --- | --- |
| `F6` | 녹화 시작/중단 (기본 매크로 탭) |
| `F7` | 현재 탭에서 선택한 매크로 재생 시작/중단 |

`F6`과 `F7` 입력은 매크로에 녹화되지 않습니다.

### 기본 매크로

1. **+ 새 매크로**를 누르거나 목록에서 매크로를 선택합니다.
2. `F6`을 눌러 녹화를 시작하고, 동작을 마친 뒤 다시 `F6`을 눌러 중단합니다.
3. 반복 횟수를 입력하거나 **무한 반복**을 선택합니다.
4. `F7`을 눌러 재생합니다. 재생 중 `F7`을 다시 누르면 중단됩니다.

> 이미 녹화된 매크로를 선택하고 녹화를 시작하면 기존 이벤트가 지워집니다. 보존하려면 먼저 매크로를 복사하세요.

### 이벤트 편집

지연과 설명은 목록에서 직접 수정할 수 있습니다. 종류와 좌표는 직접 입력할 수 없으므로 다음 순서로 추가합니다.

1. **+ 추가**로 빈 이벤트를 만듭니다.
2. 원하는 이벤트를 선택하고 **복사**를 누릅니다.
3. 빈 이벤트를 선택하고 **붙여넣기**를 누릅니다.

빈 이벤트가 남아 있는 매크로는 재생할 수 없습니다.

### 지연시간 입력 형식

| 입력 | 의미 |
| --- | --- |
| `500` 또는 `500ms` | 500밀리초 |
| `1.5s` | 1.5초 |
| `2m` | 2분 |
| `1h` | 1시간 |
| `1h12m30s` | 1시간 12분 30초 |

### 합성 매크로

1. **합성 매크로** 탭에서 **+ 새 합성**을 누릅니다.
2. **+ 기본 매크로 추가**로 실행할 매크로와 반복 횟수를 지정합니다.
3. 단발 입력이 필요하면 기본 매크로 탭에서 이벤트를 **복사**한 뒤, **+ 빈 입력 추가**로 만든 스텝에 **붙여넣기** 합니다.
4. `▲` `▼`로 순서를 조정하고 `F7`로 재생합니다.

기본 매크로의 실행 횟수는 **스텝의 반복 횟수 × 기본 매크로의 반복 횟수**입니다. 무한 반복으로 설정된 기본 매크로는 1회로 계산합니다.

합성 매크로는 기본 매크로를 이름으로 참조합니다. 참조 중인 기본 매크로의 이름을 바꾸거나 삭제하면 합성 매크로를 실행할 수 없습니다.

## 데이터 저장 위치

| 파일 | 내용 |
| --- | --- |
| `%AppData%\AutoClicker\macros.json` | 기본 매크로 |
| `%AppData%\AutoClicker\composites.json` | 합성 매크로 |

> **주의:** 녹화 중 입력한 키는 암호화되지 않은 상태로 저장됩니다. 녹화 중에는 비밀번호 같은 민감한 정보를 입력하지 마세요.

## 제한 사항

- 마우스 이동 경로, 드래그, 휠, 가운데 버튼은 녹화하지 않습니다.
- 클릭은 녹화 당시의 화면 좌표에서 재생됩니다. 창 위치나 해상도가 바뀌면 다시 녹화해야 합니다.
- 일부 게임과 프로그램은 자동 입력을 차단하거나 약관으로 금지합니다. 사용 전에 해당 약관을 확인하세요.

## 프로젝트 구조

C#과 WPF로 작성했으며 MVVM 패턴을 따릅니다. 외부 NuGet 패키지는 사용하지 않습니다.

```
AutoClicker/
├─ Models/              매크로, 이벤트, 합성 매크로 모델
├─ Services/            입력 후킹, 재생, 저장, Win32 API 선언
├─ ViewModels/          화면 상태와 커맨드
├─ MainWindow.xaml      메인 화면
├─ MacroPickerDialog.xaml  기본 매크로 선택 창
└─ app.manifest         관리자 권한 및 DPI 설정
```

| 기능 | 사용한 Win32 API |
| --- | --- |
| 입력 녹화 | `SetWindowsHookEx` (`WH_MOUSE_LL`, `WH_KEYBOARD_LL`) |
| 입력 재생 | `SendInput` |
| 전역 단축키 | `RegisterHotKey` |
